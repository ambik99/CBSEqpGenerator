CBSE Question Paper Designer — iOS & Android Installable App (PWA)
=================================================================

How to host and install in 2 minutes (no coding or App Store needed):

1. Host the folder online (free):
   - Unzip this folder (`cbse-paper-pwa`).
   - Drag and drop the unzipped folder onto Netlify Drop (https://app.netlify.com/drop)
     or upload its files to GitHub Pages / Cloudflare Pages.
   - You will get an instant HTTPS link (e.g. https://your-app.netlify.app).

2. Install on Android (Chrome):
   - Open your HTTPS link in Chrome.
   - Tap "Install App" inside the app header, or tap Chrome's menu (⋮) -> "Install app".

3. Install on iPhone / iPad (Safari):
   - Open your HTTPS link in Safari.
   - Tap the Share button (square with up arrow) -> "Add to Home Screen".

Once installed, the app appears on your home screen like a native app and works offline!
